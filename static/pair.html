Need a new pairing link?

A code expires after 30 minutes and works only once. If your login has expired or you no longer have a code, run this command in the project folder on your Mac:

python3 remote.py --pair --copy

Open the new link from your Mac's clipboard on this device. The command keeps the running tunnel and conversation in place.

Keep pairing links private. Microphone access starts only when you start a conversation.
